# モザイクマーカー

画像へモザイク、赤丸、直線、矢印、手描き線、テキスト、番号マーカーを追加し、PNGまたはJPEGで保存できるローカル完結型ツールです。

## 主な機能

- 画像のトリミング（範囲の選択・移動・サイズ調整、位置とサイズの数値入力）
- モザイク、赤丸、直線、矢印、手描き線の追加
- 白フチ付きテキストの追加と複数行入力
- クリックするたびに1、2、3…と続く番号マーカー（小・中・大の3段階）
- 配置した要素の選択、移動、削除、Undo・Redo
- ファイル選択、ドラッグ＆ドロップ、クリップボード貼り付け
- PNG・JPEGでのダウンロード

テキストツールでは画像上をクリックして入力し、Enterで確定、Shift＋Enterで改行します。配置済みテキストは選択ツールでダブルクリックすると修正できます。

## トリミングの使い方

1. 画像を開き、左の「トリミング」（ショートカット：C）を選びます。
2. 残したい範囲をドラッグします。枠の内側をドラッグすると移動、四隅・辺のハンドルでサイズを調整できます。位置・幅・高さをpx単位で入力することもできます。
3. 「切り抜く」またはEnterで確定します。「キャンセル」またはEscで中止できます。
4. 必要な編集を続け、「ダウンロード」でPNG・JPEGとして保存します。

トリミング後もモザイク・文字・図形は個別に編集できます。繰り返しのトリミングとUndo・Redoに対応し、元画像の画質を保ちます。保存されるのは確定した範囲だけです。範囲の選択中は、確定またはキャンセルするとダウンロードできます。

スマートフォンなどの狭い画面では、設定欄が画像の下に表示されます。

## ローカル起動

```bash
npm install
npm run dev
```

ターミナルに表示されるローカルURLをブラウザで開いてください。

画像は外部へ送信されず、ブラウザ内だけで処理されます。
