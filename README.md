# モザイクマーカー

画像へモザイク、赤丸、直線、矢印、手描き線、テキスト、番号マーカーを追加し、PNGまたはJPEGで保存できるローカル完結型ツールです。

## 主な機能

- モザイク、赤丸、直線、矢印、手描き線の追加
- 白フチ付きテキストの追加と複数行入力
- クリックするたびに1、2、3…と続く番号マーカー（小・中・大の3段階）
- 配置した要素の選択、移動、削除、Undo・Redo
- ファイル選択、ドラッグ＆ドロップ、クリップボード貼り付け
- PNG・JPEGでのダウンロード

テキストツールでは画像上をクリックして入力し、Enterで確定、Shift＋Enterで改行します。配置済みテキストは選択ツールでダブルクリックすると修正できます。

## 公開版

https://papayota.github.io/mozaiku-marker-tool/

## ローカル起動

```bash
npm install
npm run dev
```

ターミナルに表示されるローカルURLをブラウザで開いてください。

画像は外部へ送信されず、ブラウザ内だけで処理されます。
